什么是掺假、掉包

中转站标的是 Claude Opus、GPT，实际给你接的是别家模型，或者真假混着给。它通常不报错，只是写代码、做推理时不如官方，钱却按标的模型扣。

为什么自己问不出来

  • 问「你是谁」没用。中转站可以在你看不到的地方加一句「你是 Claude」，别家模型也会照着回答。
  • 看回答风格不靠谱。各家模型都能模仿别人的语气，几轮对话分不出来。
  • 价格便宜不等于假。便宜的站也可能是真模型，只看价格会冤枉好站，也会漏掉贵的假站。
  • 测一次也不够。真假混着给的站，一次可能碰巧是真的。
