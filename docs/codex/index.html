怎么选 GPT 中转站

  1. 先看真假。标「模型为真」的站，调用到的才是真 GPT；便宜但掺了别的模型，用起来更亏。
  2. 再看扣费和缓存。同样的标价，扣费偷偷多算、缓存不命中，实际花的钱能差一大截。带「真付费实测」的站这两项我们自己验过。
  3. 最后比价格。前两项都过了，剩下的差别基本就是价格，按你常用的型号挑便宜的。
  4. 先小额充值试用。起充低、退款无手续费的站，试错成本最低。

Codex 怎么接中转站

在中转站后台创建 key，然后编辑 ~/.codex/config.toml（Windows 在 %USERPROFILE%\.codex\config.toml）：

model = "站里给你用的模型名"
model_provider = "relay"

[model_providers.relay]
name = "relay"
base_url = "https://中转站地址/v1"
env_key = "OPENAI_API_KEY"
wire_api = "responses"

再 export OPENAI_API_KEY="中转站的 key" 启动 codex。地址末尾的 /v1 别漏，漏了会请求到站点网页上。下面只比 Codex 常用的现役型号。

常见问题

Codex 中转站哪家便宜？

按最低倍率，目前最便宜的是 XTokenMirror（0.007 倍）、A6API（0.009 倍）、SixthSense LLM（0.016 倍）。多数站在 0.37 倍上下，同一家站不同模型、不同分组倍率也不一样，按你要用的模型看对应表格。

Codex 中转站价格怎么算？

实际价格 = 官方价 × 倍率。以 GPT-6.1 Sol 为例，官方输入 $2 / 输出 $10 每百万 tokens，0.5 倍的站就是输入 ¥1、输出 ¥5。详见 中转站倍率怎么算。

Codex 能用中转站吗？

能。在 ~/.codex/config.toml 里加一个自定义提供方，base_url 填中转站地址（带 /v1）、wire_api 设成 responses，key 放环境变量即可。

codex中转站哪家好？

先看排行榜前几名：UU API、H API、OpenOx。这些站真假检测都过了，带「真付费实测」的我们用 Codex 自己掏钱跑过，扣费和标价对得上。
