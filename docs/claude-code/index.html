怎么选 Claude 中转站

  1. 先看真假。标「模型为真」的站，调用到的才是真 Claude；便宜但掺了别的模型，用起来更亏。
  2. 再看扣费和缓存。同样的标价，扣费偷偷多算、缓存不命中，实际花的钱能差一大截。带「真付费实测」的站这两项我们自己验过。
  3. 最后比价格。前两项都过了，剩下的差别基本就是价格，按你常用的型号挑便宜的。
  4. 先小额充值试用。起充低、退款无手续费的站，试错成本最低。
