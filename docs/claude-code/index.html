怎么选 Claude 中转站

  1. 先看真假。标「模型为真」的站，调用到的才是真 Claude；便宜但掺了别的模型，用起来更亏。
  2. 再看扣费和缓存。同样的标价，扣费偷偷多算、缓存不命中，实际花的钱能差一大截。带「真付费实测」的站这两项我们自己验过。
  3. 最后比价格。前两项都过了，剩下的差别基本就是价格，按你常用的型号挑便宜的。
  4. 先小额充值试用。起充低、退款无手续费的站，试错成本最低。

Claude Code 中转站哪家便宜？

按最低倍率，目前最便宜的是 XTokenMirror（0.026 倍）、Kun-Api（0.03 倍）、YeToken（0.04 倍）。多数站在 0.6 倍上下，同一家站不同模型、不同分组倍率也不一样，按你要用的模型看对应表格。

Claude Code 中转站价格怎么算？

实际价格 = 官方价 × 倍率。以 Claude Opus 5.5 为例，官方输入 $4 / 输出 $20 每百万 tokens，0.5 倍的站就是输入 ¥2、输出 ¥10。详见 中转站倍率怎么算。

Claude Code 能用中转站吗？

能。把 ANTHROPIC_BASE_URL 设成中转站地址、ANTHROPIC_AUTH_TOKEN 设成中转站的 key 即可，和直连官方用法一样。
