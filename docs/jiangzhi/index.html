中转站降智怎么测：鹈鹕测试

更新于 2026-10-27

让模型用代码画「一只骑自行车的鹈鹕」，再和官方渠道同一个型号、同一个推理档位画的对比。画得明显差一截，就是被降智了。不想自己比，在 API Ranking 填地址和 key 在线测。

什么是降智

模型名没变，但推理档位被偷偷调低、或换成了更便宜的型号。它不报错，只会让你觉得模型今天变笨了。用 Codex、Claude Code 写代码的人最容易吃亏：同样的钱，拿到的是低档模型。

为什么用鹈鹕骑自行车

题目短，但要同时画对鹈鹕和自行车、还要让它真的骑在车上，强模型和被降档的模型画出来差别一眼可见，也没法靠背答案过关。

测试步骤

  1. 选同一个型号和推理档位。中转站和官方用一样的型号、一样的档位，档位不同没法比。
  2. 用同一个提示词各画几张。一张可能碰运气，多画几张看整体水平。提示词在 API Ranking 鹈鹕测试，可以一键复制。
  3. 和官方的图对比。鹈鹕和自行车画不全、比例乱、人车分离，明显比官方差，就要警惕。

常见问题

中转站降智怎么判断？

同一道题、同一个推理档位，在官方和中转站各画几张：中转站的图明显比官方糙，就是降智了。

让模型用代码画一只骑自行车的鹈鹕，和官方同档画的对比，用来看中转站有没有偷降推理档位或换便宜型号。
