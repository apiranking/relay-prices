什么是降智

模型名没变，但推理档位被偷偷调低、或换成了更便宜的型号。它不报错，只会让你觉得模型今天变笨了、回得特别快。用 Codex、Claude Code 写代码的人最容易吃亏：同样的钱，拿到的是低档模型。

怎么测出来的

让模型用代码画「一只骑自行车的鹈鹕」。题目短，但强模型和被降档的模型画出来差别一眼可见，没法靠背答案过关。每家用 GPT-6 Astra max / high 档连画 3 张，和官方渠道的图对比。提示词、每家 3 张大图和降智案例见 API Ranking 鹈鹕测试。

中转站降智怎么判断？

同一道题、同一个推理档位，在官方和中转站各跑几次：图明显变糙、回复明显变快，就要警惕。只是慢不算证据。
